# ApplySense AI

### AI-Powered Career Operating System

**ApplySense AI** is an AI-powered Career Operating System designed to help candidates understand their professional profile, discover relevant opportunities, improve their candidacy, prepare applications, execute applications with controlled automation, prepare for interviews, identify skill gaps, and continuously improve their career strategy.

Unlike conventional job boards and standalone auto-apply tools, ApplySense connects the complete career workflow into one intelligent system:

**Understand → Discover → Match → Improve → Apply → Prepare → Measure → Learn → Improve Again**

---

## 🚀 What is ApplySense?

Job searching is fragmented.

Candidates typically use separate tools to:

* Build and optimize resumes
* Search for jobs
* Compare jobs with their skills
* Tailor resumes
* Fill repetitive application forms
* Track applications
* Prepare for interviews
* Identify missing skills
* Improve LinkedIn and GitHub profiles
* Plan what to learn next

ApplySense brings these workflows together into a unified Career OS.

The platform is designed to understand the candidate, understand the opportunity, improve candidate–job alignment, assist with execution, measure outcomes, and use those outcomes to improve future decisions.

### Core principle

> **The goal is not to maximize applications. The goal is to maximize qualified applications, interviews, and offers.**

* Relevant experience

* Responsibilities

### Anti-Hallucination Rule

ApplySense must not invent:

* Skills
* Degrees
* Certifications
* Companies
* Employment history
* Projects
* Achievements
* Metrics
* Experience

AI may rewrite and reorganize genuine information, but it should not fabricate qualifications simply to improve ATS compatibility.

# 🛡️ Application Safety

ApplySense is designed to avoid uncontrolled mass-application behavior.

Users can define rules such as:

```text
Target Roles:
Software Engineer / Full Stack Developer

Minimum Match:
80%

Locations:
India + Remote

Minimum Salary:
₹8 LPA

Maximum Applications:
15/day
```

Possible execution modes include:

### Manual

The user completes the application themselves.

### Review Before Apply

ApplySense prepares the application and requires user approval.

### Controlled Auto Apply

Applications meeting configured rules can enter the automation queue.

Sensitive, ambiguous, or high-risk application questions should require user intervention rather than AI guessing.

# 🤖 AI Trust & Safety

ApplySense follows a strict principle:

> **AI should improve the candidate's representation, never fabricate the candidate.**

The system should distinguish between:

```text
Verified User Information
        ↓
AI Recommendation
        ↓
AI-Generated Draft
```

AI-generated content must not be treated as verified candidate information without appropriate validation.

# 👨‍💻 Development

Clone the repository:

```bash
git clone https://github.com/AkhileshBandari/ApplySense.git
cd ApplySense
```

Configure environment variables using the provided `.env.example` files.

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Extension

```bash
cd extension
npm install
npm run build
```

Refer to the service-specific README files for detailed configuration and deployment instructions.
