# Copilot Trust Boundary

This document outlines the strict boundary between verified backend factual data and generative conversational output in the Phase 7A AI Career Copilot.

## Trust Hierarchy

1. **Highest Factual Authority**: Verified `CandidateContext`, existing `ResumeVersions`, and deterministic Analytics from Phase 6.
2. **Normalized Job Data**: Scraped/Parsed job requirements and existing match score evaluations.
3. **Conversational Memory**: Information provided by the user within the chat interface.
4. **AI-Generated Observations**: Responses generated by the Copilot model.

## Rules of Engagement

- **Immutability of Verified Facts**: The Copilot can read verified facts but is strictly prohibited from writing to or altering the `CandidateContext` or creating verified `Skills`/`Experiences` based solely on a user stating "I know this skill" in the chat.
- **Evidence-Based Answers**: The Copilot must base its career advice and metric evaluations (e.g., funnel conversion rates) on the deterministic data provided by the `CopilotContextBuilder`. It is instructed to never calculate its own match scores or generate hallucinatory KPI data.
- **Prompt Injection Defense**: External job descriptions and resume text are treated as untrusted string literals to prevent malicious inputs from overriding system instructions.
